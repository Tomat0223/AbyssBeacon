CivitAI pagination is handled automatically. AbyssBeacon requests the source's maximum safe batch size and follows additional pages until the requested result limit is reached or the API reports there are no more results.

Search Settings — TensorHub Art

TensorHub Art normal architecture scans use its structured website search with exact base-model filtering and automatic pagination. Expanded Creator Search remains a separate optional pass.
Expanded Creator Search
Check up to the 20 newest models from each discovered creator for projects that do not appear in TensorHub's normal discovery feeds. This can uncover additional models, but may add substantial time to the scan. Deeper creator scans are intentionally kept separate from normal source scans.
Creator Recheck Cooldown
When Expanded Creator Search is enabled, a creator is checked again only after this many hours have passed since AbyssBeacon last inspected that creator for the current base model. This never starts a scan automatically; it only reduces repeated creator requests during scans you start yourself. Set 0 to recheck eligible creators on every scan.
Full Creator Scan Limit
Maximum projects to inspect when you explicitly run Creator Scan on a TensorHub creator. Useful for creators with hundreds of models.
Search Order
Newest scans project publication order. Newest Updated uses TensorHub's latest-update ordering.
